# Halina

Halina is a Filipino restaurant prototype for checking live crowd levels and estimated wait times before visiting.

## Tech stack

Next.js App Router, TypeScript, Tailwind CSS, and local mock data only.

## Run locally

```bash
npm install
npm run dev
```

## Current status

This is a simple architecture skeleton only. It has no database, authentication, live updates, drag-and-drop, or reservations.

## Available routes

- `/` — customer restaurant feed
- `/restaurants/salu-salo` — sample restaurant detail
- `/manager` — manager dashboard
- `/manager/layout` — static layout-builder placeholder
- `/manager/analytics` — sample analytics
- `/employee` — employee table and queue dashboard
